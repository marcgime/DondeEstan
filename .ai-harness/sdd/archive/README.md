# Archivo Histórico de Cambios (OpenSpec Archive)

Este directorio almacena el historial de propuestas consolidadas y cerradas del proyecto.

## Propósito

- Preservar la trazabilidad completa de cómo y cuándo evolucionó cada capacidad del software.
- Mantener limpio y enfocado el directorio de trabajo activo `changes/`.
- Proporcionar una bitácora inmutable de deltas para auditoría humana y contexto histórico para agentes de IA.
